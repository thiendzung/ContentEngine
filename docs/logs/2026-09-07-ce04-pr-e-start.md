## Goal

Turn the selected Discovery opportunity into a bounded, traceable research package that distinguishes claims from evidence and can be locked for later writing.

Target flow:

```text
Selected ContentOpportunity
→ legitimate ContentCase
→ Evidence Research
→ atomic Claim candidates
→ exact Evidence links
→ supports / contradicts / qualifies / context-only
→ EvidenceSet draft
→ EvidenceSet lock/version
→ OriginalityPack draft
```

This PR does NOT write the Journal.

## Scope

### T04.18 — Evidence Research workflow

- start from one human-selected ContentOpportunity;
- internal MOTGU knowledge/retrieval first;
- use existing ProductionResearchRouter for bounded external research;
- selected pages must be read before they can become factual Evidence;
- explicit research gaps and stop reasons;
- preserve source/provider/parent provenance.

### T04.19 — Claim extraction workflow

- produce bounded, atomic, checkable claims;
- keep claim type/status explicit;
- no SEARCH snippet may silently become a Claim marked verified;
- avoid universal or investment/appreciation claims without adequate evidence.

### T04.20 — Evidence linking workflow

Every factual Evidence row must preserve:

- exact Claim;
- SourceDocument and/or KnowledgeChunk reference;
- locator;
- bounded excerpt actually present in the source;
- relation;
- authority metadata;
- provenance;
- verification timestamp when verified.

### T04.21 — Contradiction representation

Use existing Evidence relation contract:

- `supports`;
- `contradicts`;
- `qualifies`;
- `context_only`.

Absence of contradiction is not proof.

### T04.22 — EvidenceSet lock/version

- draft first;
- deterministic content hash;
- lock explicitly;
- locked EvidenceSet is immutable by service contract;
- changed research creates the next version instead of mutating the locked snapshot.

### T04.23 — OriginalityPack builder

Build MOTGU-owned writing material separately from external Evidence.

Possible items:

- approved MOTGU facts;
- artist/artwork material;
- studio/process detail;
- visitor/customer question in privacy-safe form;
- practical MOTGU knowledge;
- approved first-party observations.

External web summaries are not MOTGU originality.
