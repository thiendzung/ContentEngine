## T04.15 acceptance

Discovery workflow must prove:

1. internal MOTGU knowledge is checked before external research;
2. one bounded ResearchRequest is routed through ProductionResearchRouter;
3. provider output is transformed into discovery inputs without treating search snippets as customer truth;
4. MARKET observations require a readable observation/locator, not just a search snippet;
5. provider decisions, provenance, stop reason and gaps are preserved;
6. workflow can return `INSUFFICIENT_EVIDENCE` / research gaps without inventing support;
7. Discovery results are not Evidence.

## T04.16 acceptance

Opportunity handoff must prove:

1. existing `OpportunityMapService` is reused;
2. Keyword/Question Map remains a supporting tool;
3. signal dedupe preserves duplicate/repost provenance;
4. founder hypothesis remains PROPOSED unless later human/evidence workflow changes it;
5. support / contradiction / alternative explanations / missing evidence remain visible;
6. each ContentOpportunity traces to NeedHypothesis + signal refs;
7. DO_NOT_WRITE / UPDATE / REFRESH / MERGE / LINK_ONLY rules remain valid;
8. human selection is required before downstream ContentCase handoff;
9. human selection does not auto-promote hypothesis status.

## T04.17 acceptance

Each selected/discovered source can expose separate metadata dimensions:

- `source_type`
- `commercial_bias`
- `authority_hint`

Rules:

- search rank/provider score never becomes authority;
- source type is descriptive, not a truth score;
- commercial bias is a separate dimension;
- authority hint is contextual and claim-dependent later;
- metadata must preserve provenance and explain how it was derived;
- metadata can be `unknown` / nullable when evidence is insufficient;
- do not invent precise 0–100 scores.

## Failure-first tests

At minimum cover:

- internal knowledge sufficient → no external provider call;
- external discovery required → router called once through approved seam;
- search snippet cannot become MARKET observation by itself;
- unreadable forum/review page remains a gap, not fabricated customer evidence;
- duplicate/repost observations do not count as independent support;
- source rank #1 does not imply high authority;
- commercial page can be high relevance but high commercial bias;
- unknown source metadata stays unknown rather than guessed;
- human selection required for handoff;
- Discovery artifact cannot be consumed as factual Evidence directly.
