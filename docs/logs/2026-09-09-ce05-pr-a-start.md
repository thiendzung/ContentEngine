Implement the smallest CE05 Journal surface that proves bounded context assembly,
approved internal knowledge recall, and a persisted Content Memory overlap result.

- T05.1: selectable Journal ContentCase and LocaleVariant surface;
- T05.2: deterministic recall from approved, provenance-bearing KnowledgeCandidate rows;
- T05.3: deterministic memory overlap artifact that respects upstream decisions.

approval workflow, or PR-B/T05.4+ work.

specification. Existing CE02 data, CE03 Artifact, and CE03 ContextManifest contracts
remain authoritative for persistence and reproducibility.

assembly rejects unsafe or unselected inputs; only approved knowledge is recalled;
upstream `MERGE`, `LINK_ONLY`, and `DO_NOT_WRITE` decisions remain effective; repeated
context persistence is idempotent; tests run on the isolated test database with zero
provider calls.
