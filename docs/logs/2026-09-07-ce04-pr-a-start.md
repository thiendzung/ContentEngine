## Architecture decisions

1. Reuse CE02 `Source`, `SourceDocument`, `KnowledgeChunk`; do not create parallel storage unless a contract gap is proven.
2. `knowledge` owns source registry, canonical document representation, fingerprints/dedupe and chunks.
3. `research` discovers/reads providers later, then hands bounded normalized input into the knowledge ingest boundary.
4. Raw provider payload is audit material, not approved knowledge.
5. Stable hashes/IDs must be deterministic across restart/replay.
6. Re-ingesting identical content must not create duplicate SourceDocument or KnowledgeChunk rows.
7. Changed content creates a new SourceDocument version under the same Source lineage.
8. Chunk size is bounded and deterministic; no unbounded page-to-one-chunk behavior.
9. T04.6+ is explicitly deferred.

## Exit gate

Prove one source can be registered, canonicalized, versioned, deduped and chunked deterministically.

Required synthetic proof:

```text
source locator
→ register Source
→ canonical Markdown
→ content hash
→ SourceDocument v1
→ bounded deterministic chunks
→ ingest same content again
→ no duplicate document/chunks
→ ingest changed content
→ SourceDocument v2
→ new deterministic chunks
```

Full CI must pass before T04.1–T04.5 are checked.
